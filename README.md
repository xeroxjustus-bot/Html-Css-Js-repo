# Html-Css-Js-repo 🚀

A comprehensive collection of **HTML, CSS, and JavaScript** projects featuring interactive web applications, UI components, and real-world clones built with vanilla JavaScript—no frameworks, no dependencies.

## ✨ Highlights

- **Fully Functional Projects** - Complete, working applications
- **Vanilla JavaScript** - Pure JS, no frameworks or libraries
- **Responsive Design** - Works on desktop and mobile devices
- **Well-Commented Code** - Easy to understand and learn from
- **Ready to Customize** - Perfect for learning or extending
- **Zero Setup Required** - Just open `.html` files in your browser

## 📦 Projects Included

### 🤖 **Chatbot.html**
An interactive AI-powered chatbot interface built with HTML, CSS, and JavaScript. Features a clean chat UI with message history and real-time interaction.
- **Size:** ~20KB
- **Features:** Messaging interface, user-friendly design, instant responses

### 💬 **Whatsapp Clone.html**
A complete WhatsApp messaging application clone with a modern, responsive design. Includes chat bubbles, contact list, and messaging functionality.
- **Size:** ~24KB
- **Features:** Contact management, message bubbles, responsive layout, realistic UI

### 📱 **Phone.html**
A smartphone mockup/simulator interface showcasing mobile app design and interaction patterns.
- **Size:** ~29KB
- **Features:** Phone frame UI, app simulation, interactive elements

### 🔘 **Button.html**
A collection of styled button components with various states and hover effects.
- **Size:** ~2KB
- **Features:** Multiple button styles, animations, CSS transitions

### 🧪 **Science.html**
An interactive science-themed project with educational content and visual demonstrations.
- **Size:** ~3KB
- **Features:** Interactive elements, informative design

### 👍 **Facebook Logo.html**
A recreated Facebook logo component built with HTML and CSS.
- **Size:** ~1KB
- **Features:** Pure CSS logo, no images required

## 🚀 Quick Start

### Option 1: View Projects Online
1. Clone this repository:
```bash
git clone https://github.com/xeroxjustus-bot/Html-Css-Js-repo.git
cd Html-Css-Js-repo
```

2. Open any `.html` file directly in your web browser:
   - Double-click on any `.html` file, OR
   - Right-click → Open with → Your browser

### Option 2: Use with a Local Server (Recommended)
```bash
# Using Python 3
python -m http.server 8000

# Using Node.js (http-server)
npx http-server

# Then open http://localhost:8000 in your browser
```
